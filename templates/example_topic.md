## Multi-line Basic (многострочная карточка)

Формат: текст до `?` — лицевая сторона, после `?` — обратная

Опишите механизм работы GIL в Python
?
**GIL (Global Interpreter Lock)** — это мьютекс в CPython, который:

- Разрешает только одному потоку выполнять байт-код Python
- Необходим для защиты внутренних структур данных CPython
- Влияет на производительность CPU-bound задач

Для I/O-bound задач GIL не является проблемой.

## Legacy формат (обратная совместимость)

Старый формат для совместимости с предыдущими версиями:

### Вопрос: Что такое декоратор в Python?

Ответ: **Декоратор** — это функция, которая принимает другую функцию и расширяет её поведение без изменения её кода.

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("До вызова функции")
        result = func(*args, **kwargs)
        print("После вызова функции")
        return result

    return wrapper


@my_decorator
def say_hello():
    print("Hello!")
```
